# Как предложить инструмент

Приветствуются проекты, которые решают конкретные задачи VITTORA и полезны читателям канала.

1. Проверьте [каталог](CATALOG.md), [очередь](data/candidates.json) и [план](content-plan/current.json): не добавляйте дубль канонического URL.
2. Создайте предложение через Issues: ссылка на исходный репозиторий, задача VITTORA, ожидаемая польза, известные расходы и ограничения.
3. Приложите первоисточники README/LICENSE. Не называйте незапущенный инструмент протестированным.
4. Для разбора используйте [шаблон](docs/CARD_TEMPLATE.md). Для PR сохраняйте существующие поля, историю и подтверждения отправок.
5. Перед изменением реестра выполните проверки из README. Новую тему можно предлагать без установки чужого кода.

Не публикуйте токены, персональные данные, закрытые материалы или ключи доступа. Условия кодовой базы и моделей каждого проекта проверяются отдельно. Решение о выпуске принимает редакционный процесс; внешние письма, расходы и регистрации не являются частью предложения.
