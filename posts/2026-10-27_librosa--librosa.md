# Черновик: librosa

librosa — ритм трека для монтажа
Находит темп и моменты ударов в аудио. Для VITTORA рассматриваем список отметок «Воли», по которому можно выбирать смену кадров в тизере.

Плюсы: отметки в секундах дают ориентиры монтажёру; одинаковые настройки позволяют повторить анализ; локальная обработка не требует отправки трека в облако. Пригодится авторам клипов и музыкальных видео.

Нужен специалист: Python 3.12+ и зависимости, компьютер на Windows/macOS/Linux. Код ISC с сохранением уведомлений; зависимости — по своим лицензиям. Для этого анализа нет платного API и весов моделей; остаются оборудование, электричество и настройка. RAM и время ещё не измерены. Отметки требуют проверки на слух; это не автомонтаж.

Первый шаг — 30 секунд «Воли» и сверка 20 ударов вручную.
