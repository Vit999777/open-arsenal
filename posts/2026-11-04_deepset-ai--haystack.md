## Подпись

Haystack — поиск по действующим версиям материалов

Находит отрывки по словам и сужает выдачу по меткам документов. Для VITTORA проверим, можно ли исключать старые редакции глав и статей при подготовке публикаций.

Фильтр статуса позволяет искать среди действующих версий. Поля источника помогают сверить цитату. Поиск можно собрать локально без языковой модели.

Подойдёт редакциям и владельцам баз знаний. Нужен Python 3.11+ и настройка. Код Apache-2.0, платный API для пилота не требуется. Расходы — компьютер и время команды. Метки актуальности ведёт редактор, а поиск по словам может пропустить перефразировки.

Первый шаг — сравнить выдачу с фильтром и без него на 30 отрывках.
