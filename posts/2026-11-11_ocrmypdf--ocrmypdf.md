# OCRmyPDF · черновик для @open_arsenal

## Подпись к PNG

OCRmyPDF — поиск по отсканированным страницам. Программа распознаёт буквы на изображении страницы и добавляет текст, который можно найти и скопировать.

Для VITTORA это способ находить цитаты в сканах материалов к книге. Обработка идёт на своём компьютере. В смешанном PDF можно пропускать страницы с готовым текстом. Пригодится редакциям и владельцам архивов.

Для 17.14.1 нужны Python 3.11+, Tesseract с языком rus и средство чтения страниц PDF. Код MPL-2.0, платный API не нужен. Расходы — время, память и место на диске. Плохие сканы требуют ручной сверки.

Первый шаг — запустить `ocrmypdf --mode skip -l rus --output-type pdf --optimize 0 input.pdf output.pdf` на копии. 11.11.2026 сверил документацию и проверил английский пример на 16.7.0.
https://github.com/ocrmypdf/OCRmyPDF
