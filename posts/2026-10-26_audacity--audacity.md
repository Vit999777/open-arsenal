Audacity — три начала трека для тизера

Редактор помогает выбрать фрагменты музыки и сохранить их отдельными файлами. Для VITTORA рассматриваем три варианта по 18 секунд из «Воли» перед монтажом видео.

Плюсы: дорожки рядом — удобнее сравнивать варианты; экспорт размеченных областей — отдельный файл для каждого начала; локальный проект — исходник можно обрабатывать на своём компьютере. Подойдёт музыкантам и авторам подкастов.

Нужны Windows/macOS/Linux, настройка звука и место на диске. Приложение — GPLv3, обязательной покупки и API для этого сценария нет; компьютер, хранение и время оператора имеют стоимость. Возврат управления сценариями в 4.0.1 не подтверждён; мастеринг не гарантирован.
