# Promptfoo · черновик для @open_arsenal

## Подпись к PNG

Promptfoo — проверка, не сломались ли правила помощника после правки. Он сравнивает ответы с заданными условиями и показывает, где ответ их нарушил.

Для VITTORA можно сверить две версии на одних вопросах: есть ли ссылка на главу и признаёт ли помощник отсутствие источника. Один набор правил годится для повторных прогонов, а сохранённые ответы проверяются без новых запросов к модели. Подойдёт и командам со своими помощниками.

Нужны Node.js 22.22+ и Promptfoo 0.125.1. Код MIT. Для локальной сверки формата платный API не нужен. Расходы — компьютер и разметка. Смысл и верность ссылки проверяются отдельно.

Первый шаг — 10 вопросов и пять контрольных нарушений. 09.11.2026 изучена документация, пилот впереди.
