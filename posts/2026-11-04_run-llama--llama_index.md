## Подпись

LlamaIndex — поиск фрагментов книги с источниками

Собирает поисковый указатель по документам и возвращает подходящие отрывки. Для VITTORA проверим поиск по книге и журналу перед подготовкой публикаций.

К каждому отрывку можно сохранить ссылку и версию, чтобы сверить цитату. Поиск по словам можно запустить локально без языковой модели. Число результатов настраивается, чтобы редактор проверял короткую подборку.

Подойдёт редакциям и владельцам баз знаний. Нужны Python 3.10+ и настройка. Код MIT, для этого пилота облако и платный API не нужны. Расходы — компьютер и время команды. Перефразировки и русские словоформы требуют проверки.
