# pypdf · черновик для @open_arsenal

## Подпись к PNG

pypdf — обложка и глава книги в одном PDF. Библиотека берёт готовые страницы и собирает из них отдельный файл для читателя.

Для VITTORA можно выпускать ознакомительную главу, подставляя актуальную обложку. Порядок страниц задаётся в сценарии сборки, поэтому его можно повторить. Можно перенести закладки главы и добавить переход к её началу. Пригодится редакциям с несколькими версиями одного PDF.

Для pypdf 7.0.1 нужен Python 3.10+ и короткий скрипт. Код BSD-3-Clause, платные API не нужны. Учтите время настройки и ручной проверки ссылок и вёрстки. Входные файлы уже должны быть PDF.

Первый шаг — собрать обложку и одну главу, открыть итог и щёлкнуть по закладкам. 11.11.2026 проверены документация 7.0.1 и синтетический пример на 6.21.4.
https://github.com/py-pdf/pypdf
