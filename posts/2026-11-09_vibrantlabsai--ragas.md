# Ragas · черновик · 2026-11-09

Ragas — проверка, находит ли помощник нужные отрывки. Он сравнивает список найденных фрагментов с эталоном редактора и показывает, какую долю нужных фрагментов поиск вернул.

Для книги и журнала VITTORA можно сравнить две настройки на одних вопросах. Одна и та же формула позволяет повторять проверку после правок, а сравнение по номерам отрывков обходится без языковой модели. Пригодится командам с поиском по своим материалам.

Нужен Python от 3.9 по манифесту 0.4.3. Код Apache-2.0, для этой проверки платный API не нужен. Расходы — компьютер и разметка вопросов. Верность готового ответа проверяется отдельно.

Первый шаг — сверить первые пять результатов по 10 вопросам. 09.11.2026 проверены документация и код, пилот впереди.
