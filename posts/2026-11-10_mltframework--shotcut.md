# Shotcut · черновик для @open_arsenal

## Подпись к PNG

Shotcut — вертикальный экспорт без растягивания кадра. Он позволяет вручную выбрать, какая часть широкого видео попадёт в ролик для телефона.

Для VITTORA можно сделать короткий тизер из уже собранной сцены. Рамку 9:16 можно двигать по кадру, чтобы сохранить лицо и важные детали. Настройки экспорта можно сохранить и повторить для следующей серии. Подойдёт монтажёрам Shorts и Reels.

Запуск — Shotcut 26.9.27 на Windows, macOS или Linux. Код GPLv3, подписка и API не нужны. Для HD ориентир — 8 ГБ ОЗУ, нужны диск и время на экспорт. Кадрирование недоступно в режиме обработки Linear 10-bit.

Первый шаг — экспортировать 30 секунд и просмотреть стыки покадрово. 10.11.2026 проверена документация, пилот впереди.
