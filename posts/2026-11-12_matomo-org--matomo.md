# Matomo · черновик для @open_arsenal

## Подпись к PNG

Matomo — от ссылки на главу до клика «Скачать». На своём сервере он показывает, из какой кампании пришёл читатель и какое действие выполнил на странице.

Для VITTORA можно сравнить две размеченные ссылки на одну главу. Событие фиксирует нажатие, а цель позволяет увидеть его в отчёте по кампаниям. Пригодится редакциям, которые измеряют конкретное действие читателя.

Для Matomo 5.14.2 нужны веб-сервер, PHP и MySQL или MariaDB. Код GPLv3+, платный API для пилота не нужен. Расходы — сервер, хранение и сопровождение. Сбор включают после согласия в тесте. Клик сам по себе не подтверждает получение файла.

Первый шаг — сверить 12 тестовых посещений с ручным журналом. 12.11.2026 проверена документация.
