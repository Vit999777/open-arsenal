# Открытый арсенал

Полезные открытые репозитории для развития VITTORA: книги, аудио, музыка, видео, Kids, сайт, агенты, публикации, аудитория и надёжность.

Канал: https://t.me/open_arsenal

## Агент
[AGENTS.md](AGENTS.md) — рабочий цикл: задача → поиск → проверка → сравнение → карточка → обзор → пилот → оценка внедрения.

[config/research.json](config/research.json) — направления, поисковые запросы, веса оценки и срок актуальности доказательств. [data/candidates.json](data/candidates.json) — очередь исследований; пока пуста. [docs/EDITORIAL.md](docs/EDITORIAL.md) — правила публикаций.

## Инструменты
Python 3.10+; внешние Python-пакеты не нужны.

```sh
python scripts/inspect_repo.py owner/repository
python scripts/validate_catalog.py
python -m unittest discover -s scripts -p 'test_*.py'
```

Инспектор читает метаданные GitHub и ссылки на README, лицензию и релиз. Для более высоких лимитов можно передать GITHUB_TOKEN через окружение. Не сохраняйте его в репозитории. Скрипт не устанавливает найденные проекты и не заменяет проверку содержания документов.

Оценка из 100: польза VITTORA — 30; осуществимость — 25; полная стоимость — 20; поддержка — 15; интеграция — 10. Порог готовности — 75, но он не заменяет доказательства. Для ready/pilot/adopted обязательны сценарий VITTORA, сравнение, пилот, метрика, расходы, ограничения, разбор лицензии, источники и свежая дата проверки. adopted требует завершённого пилота.

GitHub Actions проверяет структуру каталога и запускает тесты при изменениях. Workflow ничего не публикует, не устанавливает найденные репозитории и не вызывает платные API.

## Фактическая готовность
Инструкции агента, инспектор и проверка каталога сохранены. Локально пройдены 6 тестов. Работающий автономный исследователь, запуск по расписанию и отправка Telegram этими файлами не включаются. Расписание и публикация в config/editorial.json пока выключены. Проверка прав нового канала и тестовая отправка остаются незавершёнными.
