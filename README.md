# Открытый арсенал

Находим полезные GitHub-проекты и объясняем, как применять их для развития **VITTORA**: книг, музыки, видео, Kids, сайта и рабочих процессов.

В каждой карточке — **конкретная польза, преимущества, требования запуска и первый проверяемый шаг**. Возможности и расходы сверяем по источникам; уровень проведённой проверки указываем прямо.

## Как устроена карточка

**Что делает → польза для VITTORA → преимущества → сложность и ресурсы → когда не подходит → пилот и метрика.**

Короткий пост сопровождается иллюстрацией. Кнопки новых публикаций открывают исходный проект и индивидуальный разбор с планом внедрения.

Уровни проверки: **изучена документация → установлен → проверен на материале VITTORA**. Статусы исследования, редакционной готовности и фактической публикации хранятся раздельно.

[Шаблон карточки](docs/CARD_TEMPLATE.md) · [Редакционная политика](docs/EDITORIAL.md)

## Контент-план

[Календарь](content-plan/README.md) содержит 60 разных кандидатов на 30 дней. В [current.json](content-plan/current.json) у каждого слота указаны тема, задача VITTORA, репозиторий, пилот и бриф иллюстрации. Проверены существование, канонические имена и отсутствие архива; редакционный разбор возможностей и лицензий выполняется перед выпуском.

Агент поддерживает горизонт следующих 30 дней, фиксирует замены и пропуски и не выпускает неподтверждённые материалы ради календаря.

## Работа агента

[AGENTS.md](AGENTS.md) — рабочие инструкции. [OPERATIONS.md](docs/OPERATIONS.md) — порядок доставки и сверки. [editorial.json](config/editorial.json) — текущие настройки. Исполнение по расписанию ведёт существующая автоматизация; её результат подтверждается отдельным журналом.

Изображения: **встроенный генератор чата → визуальная проверка → Google Диск либо Яндекс Диск → пост с прикреплённым файлом**. Платный OpenAI API и API/CLI fallback для иллюстраций запрещены. При недоступном этапе материал остаётся черновиком.

## Инструменты репозитория

Python 3.10+, стандартная библиотека.

```sh
python scripts/inspect_repo.py owner/repository
python scripts/validate_catalog.py
python scripts/validate_plan.py
python -m unittest discover -s scripts -p 'test_*.py'
```

Инспектор собирает метаданные и ссылки на первоисточники. Каталог и план проверяются автоматически при изменениях. GitHub Actions не запускает найденный чужой код и не отправляет посты.

## Источники и лицензии

Для каждого найденного инструмента проверяются собственная лицензия, зависимости и условия моделей. Публичный доступ к коду, право коммерческого применения, бесплатный API и расходы на оборудование оцениваются отдельно.

Все проекты принадлежат их авторам. Здесь публикуются ссылки, редакционные разборы и планы проверок; условия сторонних проектов сохраняются.
