# Хранение материалов

Обновлено 26.10.2026 по прямому поручению владельца.

Основной архив — Google Drive. Если файл не помещается, разрешён Яндекс Диск: приватная папка VITTORA, подкаталог open-arsenal.

1. Проверять дубли перед загрузкой, сохранять оригинальные имена и версии.
2. Для PNG: встроенный image_gen → визуальная проверка → архив → выпуск с прикреплённым изображением. Платные генераторы и API/CLI fallback запрещены.
3. Дождаться завершения загрузки. Записать archive_provider, имя/путь, URL, размер, SHA-256, verified_at. Для Google Drive — также ID и родитель из metadata.
4. Исходник и уменьшенную копию учитывать отдельно. Факт доступа к папке не означает сохранения конкретного PNG.
5. При отсутствии исходника, доступа или подтверждения оставить точный блокер, не объявлять готовность/публикацию.

Google Drive вернул storageQuotaExceeded 25.10.2026. 26.10.2026 загрузка VITTORA_STORAGE_RULES.txt в Яндекс Диск завершена с «Все файлы загружены»; показано 113 МБ из 5 ГБ. Это проверка маршрута интерактивной сессии, не доказательство архивирования PNG или доступа каждого фонового запуска. Фоновая синхронизация не развёрнута.

Не покупать место, не удалять копии и не менять общий доступ. Не повторять известный отказ Google Drive без новых оснований. Исследования и план остаются в GitHub. Пропущенные публикации пачкой не отправлять; прочие лимиты и требования сохраняются.
