## Отправка
Существующий owner-private центр Sites: `appgprj_6abe0a58a6a48191a65ebdc104e74c0b`. Его аудитория не изменяется. Доступ сервисных вызовов получать штатно через get_site; секреты не писать в файлы, команды, вывод или prompt расписания.

В центре добавлены маршруты GET `/api/arsenal-status` (права бота), GET `/api/arsenal-publish` (до 50 последних подтверждений/неоднозначных отправок), POST `/api/arsenal-publish` (одна проверенная публикация). Они используют приватный доступ Sites; внешний публичный доступ не открывается.

POST принимает repository (owner/name), caption (50–900 знаков), image_base64 (проверенный PNG до 1 MiB, размеры 100–4096 px) либо asset (из встроенной библиотеки), confirmed=true и illustration_reviewed=true. Назначение всегда @open_arsenal. При отправке изображение загружается файлом, а не ссылкой на закрытый центр. Кнопки будущих публикаций ведут на исходный GitHub-проект и индивидуальный «Разбор и план внедрения»: cards/<owner>--<repository>.md (нижний регистр, без .git). Создать и проверить разбор до отправки. Шаблон: docs/CARD_TEMPLATE.md. Иллюстрация обязательна для каждого поста; отправка без визуально проверенного PNG запрещена.

Перед Telegram отправкой D1 фиксирует уникальный repository в состоянии sending. Успех сохраняет message_id и URL. Любая неоднозначная ошибка оставляет needs_reconciliation; повторный запрос не отправляет дубль. Для уже опубликованного идентичного пакета возвращается прежнее подтверждение. Эти ограничения не заменяют редакционную приёмку.

Встроена иллюстрация WhisperX. Для новых проектов передавать свой визуально проверенный PNG через image_base64. В базе сохраняется SHA-256 изображения, а не его base64. Не подменять постер несоответствующей картинкой. Клиент: scripts/publish_telegram.py; сервисный token передаётся только JSON через stdin.

25.10.2026 подтверждены права бота и полный цикл первого выпуска: https://t.me/open_arsenal/3 (message_id=3). Обновлённый коннектор развёрнут. Ориентиры — 10:00 и 18:00 Europe/Moscow; timing_mode=flexible_schedule, точность до минуты не гарантируется. Не более двух успешных постов за московский день.
