# WhisperX — субтитры для озвучки VITTORA

Исходный проект: https://github.com/m-bain/whisperX

Направление: книга, аудиокнига и короткие видео. Проверка: 2026-10-25, изучены документация и лицензия. Установка и качество на материале VITTORA не проверены.

## Что делает
Распознаёт речь и связывает слова с моментами их произнесения — основа для синхронизированных субтитров.

## Польза для VITTORA
Получить текст и временные метки из 60 секунд авторизованной русской озвучки; подготовить субтитры к ролику. Это сценарий применения, а не выполненный результат.

## Главное преимущество
README сравнивает с openai/whisper: WhisperX добавляет выравнивание слов. Альтернатива — временные метки Whisper плюс ручная коррекция. Текущая скорость ручной работы VITTORA не измерена. По документации интерес представляет более подробная разметка слов; фактическое преимущество для нашего монтажа ещё предстоит измерить.

## Плюсы
- Временные метки слов могут помочь точнее разместить субтитры в ролике.
- Документирован локальный режим CPU: возможен пилот без подключения платного облачного API; скорость не измерена.
- CLI и Python-интерфейс описаны в README: можно рассмотреть включение в процесс подготовки роликов после пилота.

## Сложность и место запуска
**Потребуется настройка** — редакционная оценка: Python-окружение, зависимости, загрузка моделей и выбор подходящей языковой модели выравнивания. Простой онлайн-сервис без настройки этим обзором не обещается.

README: pip install whisperx, возможны ffmpeg/rust; CPU int8 поддерживается. Для GPU указан CUDA 12.8. Нужны загрузка моделей, диск, RAM и вычисления; фактическое время и расходы не измерены. Облачные демо могут быть платными. Никакие облачные аккаунты не создавались.

## Когда не подходит
Для выравнивания нужна модель соответствующего языка; цифры и наложение голосов могут давать ошибки. Разделение говорящих требует отдельного доступа и условий моделей. Качество русской озвучки пока не проверено. Если нужен готовый результат без установки, текущая ручная разметка или проверенный редактор могут оказаться проще. Экономия времени не доказана.

## Первый пилот
60 секунд чистой речи, сначала без разделения говорящих. Выбрать CPU int8 либо доступный GPU, зафиксировать версии, время и ошибки; не загружать платные API.

**Критерий:** Редакционный критерий пилота: вручную сверить 20 слов, не менее 18 с отклонением старта <=0,25 сек.; сравнить время коррекции с ручной разметкой. Это целевой порог, не обещание инструмента.

**Лимит:** один фрагмент до 60 секунд, без платных API. Допустимый объём памяти и время расчёта определяются после выбора оборудования. **Откат:** сохранить исходное аудио и вернуться к ручной разметке; не менять действующий процесс до оценки.

## Кому ещё полезно
Авторам озвученных роликов и подкастов, которым нужны субтитры и текстовая расшифровка. Применимость зависит от языка и качества записи.
