- Направление: книга и аудио / book_audio.
- Репозиторий: https://github.com/jgm/pandoc
- Проверено: 28.10.2026, documentation. Каталог reviewing: установка и пилот не выполнялись; полный ресурсный бюджет неизвестен.
- Рассматриваемый релиз: [3.13](https://github.com/jgm/pandoc/releases/tag/3.13), опубликован 26.10.2026 21:37 UTC (27.10 по Москве). README/INSTALL прочитаны из main, не все изменения main входят в релиз.

## Что делает
Конвертирует структурированный текст между форматами. Например, из Markdown (обычный текст с обозначениями заголовков) можно получить EPUB для чтения и HTML для сайта.

## Польза для VITTORA
Сценарий: одна разрешённая глава «Архитектуры человека» в редактируемом исходнике → EPUB и HTML для предварительной проверки. Финальный PDF и опубликованные издания не заменять. Текущий подтверждённый контекст — готовый PDF и сайт; наличие единого исходника, его формат и полнота пока не подтверждены. Если есть только PDF, этот сценарий не готов к запуску: сначала нужен авторский текст, а не обещание восстановить вёрстку.

## Главное преимущество
Один конвертер принимает DOCX и Markdown и выдаёт EPUB/HTML/DOCX (README). В сравнении с независимой ручной подготовкой двух версий это даёт общий источник структуры; экономия времени и качество ещё не измерены. Calibre сильнее ориентирован на библиотеку и просмотр/редактирование готовых электронных книг; Asciidoctor — на исходник AsciiDoc и отдельные расширения EPUB/PDF. Это выбор для данного сценария, не общий рейтинг.

## Подтверждённые плюсы
- Несколько форматов ввода/вывода → можно проверять несколько представлений одной главы.
- Заголовки, сноски и метаданные поддерживаются → есть основа для оглавления и ссылок, но сохранность нужно сверять.
- Официальные локальные сборки → выбранный EPUB/HTML маршрут не требует API, модели, GPU или облачного сервиса.
- Параметры запуска можно зафиксировать → повторить сборку после правок. Это свойство процесса, не результат пилота.

## Запуск
- Сложность: потребуется настройка (редакционная оценка). Нужно подготовить структурированный исходник, обложку/метаданные и проверить выход в читалке/браузере.
- Среда: свой компьютер Windows, macOS или Linux, подходящая официальная сборка. Конкретная рабочая машина/совместимость ещё не выбраны.
- Пример первого шага после отдельной подготовки среды: `pandoc chapter.md -o chapter.epub`; для HTML `pandoc chapter.md -s -o chapter.html`. Команды здесь не выполнялись.
- GPU/модель: для указанного маршрута не нужны. Интернет — для получения сборки; входные материалы держать локально, без внешних ресурсов/фильтров в первом пилоте.
- Полная стоимость по категориям: код — без лицензионной платы; веса — отсутствуют; API — отсутствуют в выбранном сценарии; хостинг — не нужен для локальной конвертации; оборудование/электричество/диск/труд/читалка — зависят от выбранного компьютера, фактические значения неизвестны. Лимит новых покупок/услуг пилота — 0 ₽. Бесплатный код не означает нулевую общую стоимость.
- Лицензия: GPL-2.0-or-later по README, условия COPYING.md; распространение изменённой программы требует соблюдения GPL. Лицензия конвертера сама по себе не выдаёт права на текст, иллюстрации и шрифты. Их права и зависимости проверяются отдельно.

## Когда не подходит
Не средство OCR, восстановления финального PDF, озвучки, перевода или гарантированного повторения печатной вёрстки. README предупреждает о потерях сложного форматирования, таблиц и полей. Для PDF нужен отдельный движок (например LaTeX), его установка/шрифты/расходы вне этого пилота. При разовой правке уже готового EPUB интерфейс Calibre может быть удобнее. Новая версия 3.13 меняет трактовку некоторых YAML значений — при использовании файлов настроек проверять их.

## Первый пилот
- Вход: копия одной разрешённой главы 1000–2000 слов в Markdown или очищенном DOCX; текстовый исходник пока не получен в этом запуске. Записать SHA-256, версию Pandoc, команды и список ресурсов.
- Ответственный: редактор VITTORA; исполнитель и машина пока не назначены.
- Действие: получить EPUB и HTML, открыть в читалке и мобильном браузере. Зафиксировать десять контрольных элементов: заголовки, абзацы, цитаты, сноски, внутренние ссылки и кириллицу.
- Метрика: 10/10 выбранных элементов сохранены в обоих форматах, 0 пропусков фрагментов при ручной сверке; записать минуты исправлений отдельно от времени конвертации, RAM и размеры выходных файлов. Это заданный редакцией порог, не полученный результат.
- Лимит: одна глава, одна сессия не более 45 минут, 0 ₽ новых услуг. RAM/диск заранее не измерены — проверить перед запуском.
- Откат: работать только в отдельной папке с копией, исходник/финальный PDF/сайт не перезаписывать. При непрохождении оставить нынешние публикации.

## Кому ещё полезно
Авторам книг, редакторам учебных материалов и владельцам журналов, которым нужны несколько форматов одного текста.
