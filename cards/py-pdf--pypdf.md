# pypdf — ознакомительный PDF с обложкой и закладками

- [Исходный проект](https://github.com/py-pdf/pypdf)
- Направление VITTORA — книга и аудиокнига
- Дата проверки — 2026-11-11
- Степень проверки — документация 7.0.1 и синтетическая проверка 6.21.4

## Что делает

pypdf берёт готовые страницы из нескольких PDF и собирает новый документ. В сценарии можно явно задать порядок страниц и перенос закладок.

## Польза для VITTORA

Собрать ознакомительный PDF книги VITTORA из актуальной обложки и готовой главы с закладками и внутренними ссылками. Поставить обложку перед готовой главой, перенести закладки и проверить переходы в копии для читателя.

## Главное преимущество

Исходная точка VITTORA — готовый PDF книги, из которого нужно получить отдельный читательский пакет. Применяемый сейчас инструмент сборки не подтверждён. Контроль — ручная сборка и просмотр тех же страниц. pypdf позволяет выбрать порядок страниц и импортировать закладки через один вызов append для главы, а PdfReader даёт возможность проверить их адреса. qpdf позволяет собрать PDF одним вызовом CLI, если достаточно выбора страниц, но документация предупреждает об ограничениях на закладки и прочие данные документа. pikepdf даёт низкоуровневый доступ через QPDF и явную работу с оглавлением, а для сценария потребуется проверить перенос навигации. Сравнение скорости и удобства предстоит.

## Плюсы

- Можно повторить сборку по сохранённому порядку файлов и диапазонов. Это позволяет менять обложку без правок главы. [Объединение PDF](https://github.com/py-pdf/pypdf/blob/7.0.1/docs/user/merging-pdfs.md)
- Импорт закладок и добавление перехода к началу главы помогают сохранить навигацию читателя. [Документация PdfWriter](https://pypdf.readthedocs.io/en/7.0.0/modules/PdfWriter.html)

## Запуск

Сложность умеренная. Нужны короткий Python-скрипт, отдельный выходной файл и проверка навигации в просмотрщиках.

pypdf 7.0.1, Python ≥3.10, локальная среда Windows, macOS или Linux с подходящим Python, отдельное окружение и пакет из официального реестра. Для доверенных незашифрованных PDF отдельные модели, GPU, сервер и платный API не требуются. AES может потребовать дополнительный пакет. Расходы включают работу редактора и разработчика, память и диск для входов, выходов и версий, электроэнергию и поддержку скрипта. Фактический денежный итог и ресурсы на файлах VITTORA неизвестны.

BSD-3-Clause для pypdf. При распространении соблюдать условия уведомлений. Лицензии дополнительных библиотек, обложки, иллюстраций и шрифтов оцениваются отдельно.

## Когда не подходит

Входы — готовые доверенные PDF. Для нового макета нужен исходный инструмент вёрстки, для сканов с поиском нужен отдельный OCR. Внутренние ссылки, сложные формы, электронные подписи и специальные режимы PDF требуют отдельной приёмки. Изменённый файл не использовать как замену подписанного мастера. Закрытый #3953 относится к потере внутренних ссылок в старой версии и служит основанием для проверки переходов после сборки.

## Первый пилот

На копиях взять одну обложку и пятистраничный фрагмент главы с двумя закладками и одной внутренней ссылкой. Собрать файл на pypdf 7.0.1, сверить с ручной контрольной сборкой и открыть результат в двух PDF-просмотрщиках. Лимит — 30 минут после подготовки среды, без покупок. Ответственные роли — редактор и разработчик, исполнители не назначены. Откат — оставить исходники и ручной контрольный файл.

Критерий успеха — 6 из 6 страниц в заданном порядке, 2 из 2 закладок и внутренняя ссылка ведут на заданные страницы в обоих просмотрщиках, обложка и края страниц отображаются целиком. Записать минуты и размер файла, отдельно проверить неизменность исходников по SHA-256.

## Кому ещё полезно

Редакциям, которые выпускают ознакомительные главы, методички и другие PDF с общей обложкой.
