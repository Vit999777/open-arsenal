## Что делает
FFmpeg преобразует видео и звук по заданным командам. Входящий в проект ffprobe читает параметры файла: формат, дорожки, длительность и другие технические сведения.

## Польза для VITTORA
Сценарий: после монтажа 18-секундного тизера «Воля» получить отчёт о размере кадра, частоте кадров, длительности и наличии звука, затем проверить полное декодирование. При необходимости — создать отдельную копию для доставки. Это план применения, а не полученный результат.

Текущий процесс — монтаж HyperFrames и проверка экспорта. FFmpeg рассматриваем как отдельный проверяемый шаг после него, без замены творческого монтажа. Он уже может использоваться внутри существующих инструментов; отдельный репозиторий в каталоге не доказывает новое внедрение. Слабое начало, драматургию и привлекательность ролика техническая конвертация не исправляет.

## Главное преимущество
Для автоматической проверки удобен машиночитаемый отчёт ffprobe: его можно сопоставить с заранее заданными требованиями. Основание — [документация ffprobe](https://github.com/FFmpeg/FFmpeg/blob/master/doc/ffprobe.texi), разделы Description, show_entries и Writers. Это преимущество способа интеграции, не измеренная экономия времени.

## Плюсы
- ffprobe выдаёт структурированные данные → можно проверять параметры одинаковым правилом для разных роликов.
- Команды задают входы, выходы и выбор дорожек → можно явно контролировать, какой звук включён в копию.
- Локальная обработка → для выбранного сценария не нужны генеративные модели и внешний API; затраты вычислений остаются.

## Запуск
- Сложность: потребуется настройка. Это редакционная оценка: нужны выбор сборки, кодеков, дорожек и правил проверки ошибок.
- Среда: компьютер/сервер Windows, macOS или Linux/Unix; платформенные инструкции прочитаны в doc/platform.texi. Простой программный экспорт может работать на CPU; GPU — отдельная необязательная конфигурация.
- Сборка из исходников: configure и GNU Make >=3.81; внешние библиотеки по умолчанию выключены. Для x264 нужна соответствующая сборка. Команды из README не исполнялись.
- Код: без обязательной покупки лицензии; это не нулевая полная стоимость.
- Модели: не нужны для данного пилота.
- Вычисления: CPU/возможный GPU, электричество или аренда; RAM/пик памяти и длительность для нашего материала не измерены.
- Диск: исходник + экспорт + отчёты; требуемый объём зависит от входа и кодека, ещё не измерен.
- API и хостинг: для локального пилота не требуются. При серверной автоматизации отдельно оплачиваются сервер, хранение и сопровождение; итоговая сумма неизвестна.
- Время настройки/сопровождения: не измерено. Платные аккаунты не создавались, услуг не покупали, код не устанавливали.

## Лицензия и ограничения
Прочитан [LICENSE.md](https://github.com/FFmpeg/FFmpeg/blob/master/LICENSE.md): основа LGPL v2.1+, опциональные GPL-компоненты меняют лицензию сборки. libx264/libx265 перечислены как GPL-зависимости; nonfree-комбинации могут запрещать распространение бинарного файла. Проверять нужно конкретную сборку и её зависимости. Права на видео/музыку и возможные патентные обязательства кодеков не возникают автоматически из лицензии кода; отдельного заключения по ним нет.

Перекодирование с потерями меняет изображение и звук. Автоматическое масштабирование может обрезать важные элементы; неверные настройки — изменить цвет или синхронизацию. Наличие аудиодорожки не доказывает слышимость и художественное качество. Полное декодирование не подтверждает приём файла площадкой.

## Когда не подходит
Когда нужно придумать сцены, сделать сильный монтаж или оценить эмоцию зрителя. Для разового ручного экспорта при отсутствии навыков командной строки сначала сравнить существующий редактор или Shutter Encoder. Для HDR, переменной частоты кадров и аппаратных кодеков нужен отдельный тест; результаты обычного SDR-файла на них не переносить.

## Первый пилот
- Ответственный: технический редактор VITTORA; конкретный исполнитель пока не назначен.
- Вход: разрешённый финальный 18-секундный тизер «Воля», копия без изменения оригинала.
- Действие: зафиксировать версию и параметры сборки; ffprobe — отчёт JSON; полное декодирование; один экспорт с явно выбранными видео- и аудиодорожками. Сверить с текущим экспортом HyperFrames. Перед запуском проверить наличие нужного кодека.
- Успех: целевой файл 1080×1920, заданная частота кадров сохранена, аудиодорожка присутствует, отклонение длительности не более 0,1 с, декодирование без ошибок; вручную проверить начало/середину/конец и синхронизацию. Это редакционные критерии, не результаты.
- Метрики: время отчёта/экспорта, размер входа и выхода, пик RAM, число ошибок декодирования и замечаний при просмотре; сравнить ручное время с текущим процессом.
- Лимит: плановое ограничение — один ролик, один экспорт, до 30 минут настройки, без покупок и облачных API. Доступные CPU/RAM/диск для рабочего пилота ещё не подтверждены.
- Откат: удалить только тестовые копии и отчёты; исходник и монтажный проект сохранить.

## Кому ещё полезно
Авторам роликов, монтажёрам и редакциям, которым нужна повторяемая техническая проверка файлов или пакетный экспорт.
