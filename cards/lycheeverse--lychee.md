# Lychee — поиск битых ссылок до выпуска статьи

- Исходный проект: https://github.com/lycheeverse/lychee
- Направление VITTORA: сайт и журнал
- Дата: 2026-11-08
- Степень: проверены документация, лицензии, требования, релизы и открытые замечания. Установки и пилота не было.

## Что делает

Извлекает адреса из файлов и проверяет ответы. Отчёт помогает найти ссылку, которую нужно перепроверить или заменить.

## Польза для VITTORA

Проверить копии трёх статей в Markdown с ограниченным списком ссылок, затем передать редактору отчёт с исходным файлом и адресом для правки.

## Главное преимущество

В отличие от htmltest, ориентированного на готовую HTML-сборку, Lychee принимает исходные Markdown и HTML в одном инструменте. LinkChecker тоже работает с локальными документами, но его README ориентирует на обход сайта и требует Python для выбранного способа установки. Для проверки ссылок в отдельных статьях достаточно передать Lychee нужные файлы. Ручная сверка выбранных ссылок — контрольный вариант, действующий процесс редакции отдельно не обследован.

## Плюсы

- Принимает Markdown и HTML. Можно сверять и исходную статью, и готовый файл. [README](https://github.com/lycheeverse/lychee/blob/master/README.md)
- Поддерживает JSON-отчёт. Если пилот пройдёт, его можно разбирать в процессе сборки без ручного копирования адресов. [Документация](https://lychee.cli.rs/)

## Запуск

Сложность невысокая для локального прогона, потребуется определить входные файлы и правила для сетевых отказов.

Готовый бинарник 0.24.2 для поддерживаемой архитектуры Linux, macOS или Windows, контроль SHA-256 по релизу. При сборке этого тега Rust от 1.88. Для сетевых ссылок нужен доступ к целевым адресам. Код без лицензионной платы, API, модели, GPU и внешний хостинг в локальном пилоте не нужны. Полные затраты включают время настройки и разбора исключений, компьютер, трафик, хранение отчётов, а при переносе в CI — время исполнителя и хранение по тарифу площадки. Фактические объёмы и цена неизвестны.

Основной код под MIT или Apache-2.0 на выбор. При распространении соблюдать условия выбранной лицензии и уведомления зависимостей. Аудит комплекта сторонних лицензий не проводился.

## Когда не подходит

Таймаут, 403 или 429 не доказывают, что страница сломана. HTTP 200 не гарантирует нужное содержание. Не заменяет проверку действий в браузере, входа и ссылок, появляющихся только после JavaScript. Статусы и правила обхода целевых сайтов проверять отдельно.

## Первый пилот

На трёх копиях статей собрать 12 ссылок с заранее записанными ожидаемыми результатами. Включить три контролируемых HTTP 404 на локальном тестовом сервере и девять рабочих ссылок. Один прогон Lychee с JSON и ручная сверка того же списка. Лимит 60 минут после подготовки среды, без покупок. Роль — редакционный QA, исполнитель не назначен. Откат — оставить проверку ручной и не подключать автоматический барьер выпуска.

3/3 ожидаемых 404 обнаружены, 0/9 рабочих ссылок ошибочно отмечены на контрольном наборе. Замерить длительность прогона и ручной сверки, пик RAM и размер отчёта. Таймауты и ответы ограничений считать отдельно. Пилот предстоит.

## Кому ещё полезно

Редакторам журналов и авторам документации с большим числом ссылок.
