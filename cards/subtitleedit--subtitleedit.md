# Subtitle Edit — правка субтитров перед выпуском Shorts

- Исходный проект: https://github.com/SubtitleEdit/subtitleedit
- Направление VITTORA: video
- Дата проверки: 2026-11-01
- Степень проверки: documentation; установка и пилот не выполнялись; каталог reviewing.

## Что делает
Позволяет исправлять текст субтитров и время появления реплик рядом с видео и рисунком звуковой дорожки. Это редактор, а не гарантия правильного распознавания речи.

## Польза для VITTORA
Предполагаемый сценарий: взять копию 60-секундного Shorts с согласованной озвучкой VASKO и SRT (текст с временем каждой реплики), проверить границы фраз и переносы строк перед финальным монтажом. Проблема — ошибки в титрах после автоматической разметки. В текущем процессе VITTORA используются программная сборка и ручная сверка; время работы и число ошибок не измерены, наличие установленного редактора не подтверждено. Этот инструмент не исправит несовпадение губ и голоса.

## Главное преимущество
По сравнению с правкой временных меток в текстовом файле — наглядный контроль речи, видео и титров в одном окне (официальная документация Audio Visualizer). Это подтверждённая возможность, но выигрыш во времени на VITTORA ещё не измерен.

## Плюсы
- Локальное редактирование — основную правку можно проводить без отправки медиа внешнему сервису; README отдельно предупреждает о передаче данных при включении онлайн-функций.
- Звуковая волна и правка границ реплик — возможность сопоставить титр с речью; скорость/точность предстоит измерить.
- Проверка распространённых ошибок — дополнительный список мест для редакторской сверки; не автоматическая гарантия качества.

## Запуск
- Сложность: потребуется настройка (редакционная оценка): выбрать сборку под ОС, открыть видео/SRT, согласовать переносы и профиль проверки. Сборка исходников для первого пилота не нужна.
- Windows: README требует Windows 10 22H2 build 19045+.
- macOS: минимум 12, рекомендована 14+; self-contained DMG включает libmpv/ffmpeg.
- Linux: Flatpak включает зависимости; native tarball требует mpv/ffmpeg для видео. Отдельный .NET для готовых сборок по README не нужен.
- Для первого пилота использовать стабильную сборку v5.3.0, предварительно сверив её требования с текущим README. Документация main может описывать более новые функции.
- Код/лицензионный платёж: MIT не требует покупки. Модели в ручном пилоте не нужны, GPU для этого сценария не заявлен обязательным.
- Вычисления: компьютер, диск, электричество и время редактора; RAM/диск/время для нашего ролика не измерены. Хостинг не нужен. Облачные перевод/AI/API исключены из пилота; тарифы провайдеров не проверялись. Полная сумма в рублях неизвестна до выбора машины и замеров.
- MIT требует сохранения уведомления при распространении копий кода; права на видео/голоса/модели отдельно. Лицензии ffmpeg/libmpv и иных распространяемых компонентов не заменяются MIT приложения.

## Когда не подходит
Если нужна полностью автономная серверная обработка без визуального редактора, если ОС старее требований или проблема в lip-sync самого видео. Для пары правок привычный монтажный редактор может быть проще. Сложное оформление ASS сравнить с Aegisub. Не включать платные/онлайн-сервисы по умолчанию.

## Первый пилот
- Вход: разрешённая копия 60 секунд русской озвучки VITTORA с видео и SRT, исходники не менять.
- Ответственный: редактор VITTORA; запуск отдельной задачей, не выполнен этим обзором.
- Действие: открыть стабильную сборку, вручную сверить 20 реплик, исправить, экспортировать отдельный SRT и проверить в финальном вертикальном кадре.
- Успех (редакционный целевой порог, не результат): >=18/20 стартов с отклонением <=0,25 секунды относительно ручного эталона; 0 отрицательных интервалов/непреднамеренных перекрытий; 0 обрезанных строк на телефоне.
- Измерить время коррекции тем же редактором против текущего способа, память и размер файлов; заранее экономию не обещаем.
- Лимит: 1 ролик, 30 минут на первичную пробу как редакционный бюджет; денег на API/аккаунты 0. Реальные RAM/диск неизвестны.
- Откат: удалить только экспериментальные результаты по отдельному решению, вернуть исходный SRT, оригинал не перезаписывать.

## Кому ещё полезно
Авторам коротких видео, интервью и учебных роликов, которым нужна ручная приёмка титров.
