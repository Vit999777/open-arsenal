## Что делает

Позволяет собрать этапы обработки изображения, видео или аудио в схему из связанных блоков. Схему можно сохранить, открыть снова и передать другому исполнителю.

## Польза для VITTORA

Предполагаемый сценарий: сохранить настройки подготовки иллюстрации к рилсу «Воля», а затем открыть их повторно без восстановления параметров по переписке. Видеогенерация требует отдельно выбранной модели: ComfyUI сам по себе не является моделью Wan.

Текущий процесс по доступному контексту — монтаж изображений, музыки и титров в HyperFrames. ComfyUI рассматриваем как дополнительный этап подготовки исходных сцен. Никакой замены действующего процесса не выполнено. Ускорение, экономия и качество не измерены.

## Главное преимущество

По сравнению с восстановлением настроек из переписки README явно описывает сохранение и загрузку схем в JSON и восстановление настроек из поддерживаемых медиа. Это основание сравнения по переносимости настроек, а не доказательство лучшего видео. InvokeAI и SwarmUI тоже имеют схемы; уникальность этой функции не заявляется.

## Плюсы

- Сохранение схем и начальных параметров случайности → возможность передать рецепт обработки. Побитовое совпадение результата между платформами не гарантируется.
- Локальная работа и отключение необязательных платных API-блоков → возможность выбрать процесс без внешней генерации после получения зависимостей и моделей.
- Локальный программный интерфейс и очередь → возможная основа подключения к центру управления. Интеграция не реализована и не испытана.

## Запуск

- Сложность: потребуется настройка; редакционная оценка.
- Причина: подобрать совместимые версии Python/PyTorch/драйвера, модель, схему и память; дополнительные блоки могут привнести свои зависимости.
- Среда: Windows/Linux/macOS, локальный компьютер либо отдельный сервер. README рекомендует Desktop для Windows/macOS; ручной запуск описан отдельно.
- Requirements: torch, torchvision, transformers >=4.50.3, av >=17.0.0; frontend и шаблоны закреплены в requirements. Часть зависимостей без точных версий: для пилота нужен отдельный снимок окружения.
- README рекомендует Python 3.13; это не гарантия совместимости каждого расширения. CPU-режим описан, но пригодность его для видео не установлена.
- RAM/VRAM/диск: точные значения для нашего процесса неизвестны до выбора модели и разрешения. Общее заявление README о малой памяти не считаем гарантией запуска нужной видеомодели.
- Код: лицензионный платёж за локальное ядро не требуется. Это не нулевая полная стоимость.
- Модели: объём загрузки, права коммерческого использования и условия доступа ещё не проверены для конкретного набора.
- Вычисления: покупка/амортизация оборудования, электричество либо часы аренды GPU; тариф и длительность неизвестны.
- Хранение: веса, окружение, результаты и резервные копии; объём и тариф неизвестны.
- API/облако: необязательны для выбранного локального сценария; платные Comfy Cloud и API-блоки существуют, здесь не подключались.
- Работа специалиста: настройка, обновления и контроль результата; трудозатраты не измерены.
- Полная стоимость: TCO = оборудование/аренда + электричество + хранение/трафик + опциональные API + сопровождение. Числовой итог пока не определён. Фактических платных операций в этом исследовании нет.
- Лицензия: [LICENSE GPL v3](https://github.com/Comfy-Org/ComfyUI/blob/master/LICENSE). Условия распространения кода не заменяют условий весов и дополнений; права на материалы проверяются отдельно.

## Когда не подходит

Если требуется только собрать готовые изображения с музыкой, текущий монтаж может быть проще. Не подходит как обещание бесплатного видео без GPU, как гарантия единого персонажа или как готовый автоматический издатель. До выбора модели и проверки её условий к видеопилоту не переходим. Исследование не разрешает установку непроверенных сторонних расширений.

## Первый пилот

- Предусловие: выбрать одну модель и официальную схему, проверить её лицензию и доступное оборудование. Пока не выполнено.
- Входной материал: копия одного разрешённого кадра VITTORA для «Воли», без закрытых данных.
- Действие: на зафиксированной версии сохранить схему, закрыть и вновь загрузить, проверить параметры и выполнить два запуска, если ресурсы согласованы.
- Ответственный: технический исполнитель VITTORA; Виталий оценивает художественную пригодность.
- Успех: все выбранные параметры (модель, seed, размер, шаги и текст задания) восстановлены после загрузки; два запуска завершены без ошибки. Записать время, пик памяти и размер результата. Это редакционный критерий, не пройденный тест.
- Лимит: один кадр, два запуска, до 60 минут работы исполнителя; закупки и платные API — 0. Вычислительный лимит не определён до выбора оборудования; аренду автоматически не запускать.
- Откат: удалить отдельное тестовое окружение после сохранения результатов; оригиналы и процесс HyperFrames не менять.
