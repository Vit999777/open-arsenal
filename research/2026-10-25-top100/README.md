## Главный вывод

Для ближайших пилотов VITTORA наибольшую практическую ценность дают инструменты подготовки файлов, субтитров, проверки сайта, подтверждения работы расписаний и резервирования. Генеративное видео и локальные LLM остаются важным направлением, но их применение требует отдельного выбора моделей, оборудования и бюджета.

Рекомендуемый небольшой набор для оценки: **FFmpeg, Subtitle Edit, WhisperX, Lighthouse, lychee, Playwright, Healthchecks, Uptime Kuma, restic, MarkItDown, Pandoc и Umami**. Сначала сверить, какие возможности уже обеспечены существующим центром; не устанавливать дубли.

## Что именно проверено

- У 100 проектов прочитаны README и файл лицензии, получены метаданные GitHub, проверены страница релизов и выборка до трёх открытых записей issues. Issues API включает pull requests; это учтено в JSON.
- Версии файлов README/LICENSE зафиксированы blob SHA; ссылки и снимки метаданных сохранены в JSON.
- Для 116 действующих кандидатов собраны README/LICENSE; из них выбрана сотня под задачи VITTORA. Это кураторская выборка, не исчерпывающий мировой топ.
- Инструменты не устанавливались, нагрузка и качество результата не измерялись. Это документальный анализ, не аудит безопасности и не свидетельство готового внедрения.
- В основную сотню не включены рассмотренные репозитории со смешанным proprietary/OSS-составом; они перечислены отдельно. Публичный исходник сам по себе не подтверждает open source: [определение OSI](https://opensource.org/osd).

## Как читать баллы

Польза VITTORA — 30%, осуществимость — 25%, ожидаемый профиль затрат — 20%, proxy активности — 15%, интеграция — 10%. Каждая оценка 1–5; результат — сумма вес × оценка / 5. Первые, вторые, третьи и пятые компоненты являются **редакционными суждениями по документации**. Денежная экономия не измерена.

Активность — только давность последнего push: до 30/90/180/365 дней дают 5/4/3/2, более года — 1. Для официальных зеркал это особенно грубый показатель. Звёзды приведены как снимок и в балл не входят. Одинаковые баллы упорядочены по имени. Разница в 1–3 балла не является доказательством превосходства. 100 баллов — максимум этой модели, не обещание идеального продукта.

**P0** — первые сценарии пилотов VITTORA; **P1** — следующая очередь сравнения; **P2** — полезно при подтверждённой специальной потребности. Приоритет пилота отдельно учитывает текущие задачи и может отличаться от места по формуле.

## С чего начать: четыре небольших пакета пилотов

1. **Выпуск контента:** один разрешённый аудиофрагмент → расшифровка/субтитры → ручная коррекция → короткий тестовый ролик. Сравнить время правок и синхронность.
2. **Сайт:** одна страница → Lighthouse/axe/проверка ссылок → одно исправление → повторный замер в тех же условиях. Проверить путь к книге и плееру.
3. **Надёжность:** тестовые файлы → резервная копия → восстановление; отдельная задача → сигнал завершения и контролируемый пропуск.
4. **Знания и аналитика:** 20 разрешённых документов и 10 вопросов либо две реальные выгрузки. Сравнить простое решение с одной альтернативой. Внедрять по результату, сохраняя текущий рабочий процесс.

Не требуется устанавливать все 100 проектов. Выбирать один пакет и ограниченный пилот, заранее фиксируя критерий успеха и доступные ресурсы. Конкретные расходы, аккаунты, серверы и перенос production не разрешаются одним лишь включением в рейтинг.
